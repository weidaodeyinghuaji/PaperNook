# PaperTodo V1.1 发布安全实施报告

日期：2026-09-20  
分支：`feature/v1.1-release-safety`  
版本：`1.1.0`  
状态：代码实现完成；正式签名与干净 VM 发布验收待外部资源。

## 已实现

- 发布信任链：GitHub Actions OIDC + Azure Artifact Signing、Authenticode 复核、严格 `release-manifest.json`、SHA-256/长度/版本/distribution 校验，缺少 publisher subject/SPKI 时失败关闭。
- 可回滚更新：稳定/Beta 通道、每日检查、可选自动下载、用户确认安装、父进程等待、分阶段 EXE 替换、健康确认和旧版回滚。
- 四类位置：Data、Notes、Cache、Backups；`storage.json` schema 2 自动兼容 schema 1，普通/便携默认值、路径防重叠、重启迁移与源数据保留。
- 可验证备份：`.papertodo-backup` schema 1，核心 JSON 写锁快照、LMDB 在线快照、插件 flush、可选 Notes、确定性条目、长度/SHA-256 二次验证、取消清理、每日备份和仅自动包保留策略。
- 安全恢复：恶意路径、重复项、压缩比、单文件/总大小、缺失/额外项、哈希和格式版本预检；同卷 staging、启动前目录切换、`Data.before-restore-*`、中断续作、健康确认前二次启动回滚。
- 可视化中心：备份位置、占用/剩余空间、立即备份/取消、异步健康验证列表、自动策略、两步恢复确认，以及可信更新状态和操作。
- 插件安全模式：`Starting → LoadingState → DiscoveringPlugins → ActivatingPlugin → Running → CleanExit` 健康记录；只在连续两次插件阶段失败后隔离，运行期断电不误判；`--safe-mode`、逐插件启停、指纹更新重置和一次试运行；内置 Markdown 始终启用。
- 进程级崩溃检查：独立 harness 在 barrier 后强制结束子进程，覆盖 state-save、storage-config、backup-create、restore-switch、update-replace、plugin-health 共 14 个用例。
- 文档：中英文 README、Changelog、用户指南，以及架构、决策、崩溃恢复矩阵均已更新。

## 已知限制与正式发布门禁

- 本机没有真实代码签名身份，未执行正式 Authenticode 签名。发布前必须配置 Azure OIDC、Artifact Signing account/profile、`PAPERTODO_PUBLISHER_SUBJECT` 和 `PAPERTODO_PUBLISHER_SPKI_SHA256`，并验证时间戳与下载后签名。
- 未在干净 Windows 10/11 VM 完成 self-contained/no-runtime、普通/便携、V1.0 数据升级、无/有 WebView2、更新/回滚/恢复/安全模式矩阵；真实掉电只能在 VM 快照中演练。
- 稳定版仍需至少 3 天 RC 日常使用，并由 workflow 的 `stable_release_confirmed=true` 门禁发布。
- 实施前已存在的 `PaperTodo.LifecycleChecks` 失败仍可复现：`progressive selection did not fill short-note slots`。另有不在本次文件范围内的 Todo navigation `Native End then Up` 断言连续失败；均未用本计划代码掩盖或改写。
- 现有本地 LMDB DLL 缺少新导出时使用锁内兼容快照；正式发布 workflow 会从源码重建含 `mdb_env_copy2` 的 DLL。
- 没有执行 commit、push、创建 Release 或删除用户文件。

## 清理记录

- 已删除本次双分发验证的临时 publish 目录和 3 个下载完成/中断后的 SDK/Zig ZIP；保留已安装的本地 .NET 10 工具链用于复现。
- 早期 crash runner 曾错误地把测试 apphost 当作 `dotnet` host，递归生成 10,762 个仅含隔离测试数据的 `%TEMP%\PaperTodo-crash-*` 目录；runner 已改为从当前 runtime 目录解析真正的 `dotnet.exe`，全部临时目录已逐个限定父目录并清理，复跑 14/14 通过且不留成功用例目录。

## 使用入口

- 备份/更新：设置 → 备份与更新。
- 四目录：设置 → 数据与存储。
- 插件隔离：设置 → 插件；命令行可用 `--safe-mode`。
- 崩溃矩阵：`dotnet run --project tests/PaperTodo.CrashRecoveryChecks/PaperTodo.CrashRecoveryChecks.csproj -c Release`。
- 正式发布前按 `doc/CRASH_RECOVERY_TEST_MATRIX.md` 和 `.github/workflows/release.yml` 完成外部门禁。
