05 / 为什么是 PaperNookWhy PaperNook

几张纸，不多一层管理。A few papers. No extra manager.

01

纸片优先

Paper-first

没有主窗口，没有管理器。每张纸都是独立窗口，位置和内容自动保存。

No main window or manager. Every paper is an independent, auto-saved window.

02

多屏支持

Multi-screen

每个屏幕边缘都有独立队列，胶囊可以换边，也可以直接拖到另一块显示器。

Each display has its own edge queues. Move capsules between sides or displays.

03

待办关联笔记

Link notes

从任务行直接打开关联笔记；关联脚本后，也能按需直接运行。

Open a linked note from its task row—or optionally run a linked script.

04

本地图片

Local images

支持粘贴、拖入或菜单选图，图片保存在本地 LMDB 文件里。

Paste, drag, or choose images. They stay in a local LMDB file.

05

全局快捷键

Global hotkeys

可绑定显示、隐藏、切换和新建纸片，并用数字键快速打开边缘胶囊。

Bind show, hide, toggle, and new-paper actions, plus number keys for edge capsules.

06

WPF 原生实现

Native WPF

不是 Electron 或 Web 套壳，支持高 DPI、多屏与触控板手势。

Native WPF—not Electron or a web wrapper—with high-DPI, multi-screen, and touchpad support.

06 / Q & A

开始之前，你可能想知道。Before you start, a few answers.

支持哪些 Windows 版本？Which Windows versions are supported?

Windows 10 / 11 x64 使用正式版；Windows 7 SP1 x64 另有尽力兼容（Best Effort）版，请在 GitHub Releases 下载自包含版本。

Use the standard build on Windows 10/11 x64. A separate best-effort build for Windows 7 SP1 x64 is available from GitHub Releases; use the self-contained package.

如何备份和迁移数据？How do I back up or move data?

退出 PaperNook 后复制整个程序文件夹即可，纸片、设置和笔记图片会一起迁移。

Exit PaperNook and copy the whole app folder. Papers, settings, and note images move together.

为什么首次运行会出现 SmartScreen 警告？Why does SmartScreen appear on first run?

项目暂未购买商业代码签名证书。选择“更多信息 → 仍要运行”即可，每台电脑通常只需确认一次。

The project does not yet use a commercial code-signing certificate. Choose “More info → Run anyway”; each PC normally asks once.

可以自定义主题和字体吗？Can I customize themes and fonts?

提供四套配色，支持跟随系统或手动切换浅色、深色主题，也可以放入自定义字体文件。

Choose from four palettes, follow the system or switch light and dark themes, and add a custom font file.

支持全局快捷键和启动参数吗？Does it support global hotkeys and launch parameters?

可以绑定常用全局快捷键，也支持 --show、--hide、--toggle、--new-todo 和 --new-note 等启动参数。

Bind common global hotkeys and use launch parameters such as --show, --hide, --toggle, --new-todo, and --new-note.

02 / 胶囊模式Capsule mode

桌面要清净，就把纸折成胶囊。

Clear the desktop.Fold papers into capsules.

纸片没有消失，只是收进当前屏幕的边缘队列。鼠标靠近时滑出，点击便回到原来的展开状态；也可以直接拖到另一块屏幕。

The paper is not gone; it joins the edge queue on the current screen. Hover to reveal it, click to restore it, or drag it directly to another display.

  • 自动加入左右边缘队列，悬停滑出Joins a left or right edge queue; hover to reveal
  • 点击恢复纸片，也可记住展开位置Click to restore, with an option to remember position
  • 主胶囊一键收起队列，多屏之间直接拖动Fold a queue from its master capsule; drag across displays

03 / Markdown 渲染Markdown rendering

Markdown，三种阅读密度。

Markdown,three reading levels.

原文完整保留标记；基础模式给语法加上轻量高亮；增强模式进一步整理标题、列表、强调和分隔线。三档会自动轮播，手动选择后停在你的选择。

Raw keeps every mark. Basic adds lightweight syntax highlighting. Enhanced further refines headings, lists, emphasis, and rules. The demo cycles automatically and pauses when you choose a mode.

Q / A

常见问题

Common questions

支持哪些 Windows 版本？Which Windows versions are supported?

Windows 10 / 11 x64 使用正式版；Windows 7 SP1 x64 另有尽力兼容（Best Effort）版，请在 GitHub Releases 下载自包含版本。

Use the standard build on Windows 10/11 x64. A separate best-effort build for Windows 7 SP1 x64 is available from GitHub Releases; use the self-contained package.

数据如何备份和迁移？How do I back up or move my data?

退出 PaperNook 后复制整个程序文件夹即可。纸片内容、设置和笔记图片会一起带走，数据在 data.json 和 note-assets.lmdb 里。

Exit PaperNook and copy the whole app folder. Papers, settings, and note images move together in data.json and note-assets.lmdb.

为什么首次运行会出现 SmartScreen 警告？Why does SmartScreen appear on first run?

项目暂未购买商业代码签名证书。选择“更多信息 → 仍要运行”即可，每台电脑通常只需确认一次。可以在 GitHub Release 页面校验文件哈希。

The project does not yet use a commercial code-signing certificate. Choose “More info → Run anyway.” You usually only need to confirm once per PC. Verify file hashes on the GitHub Release page.

可以自定义主题和字体吗？Can I customize themes and fonts?

提供暖纸、墨、林、霞四套配色方案，支持跟随系统或手动切换浅色/深色主题。可以选择系统默认、微软雅黑、等线，或放入自定义字体文件（papertodo.ttf / papertodo.otf）。

Four color schemes: Warm, Ink, Forest, Rosy. Supports system theme or manual light/dark toggle. Choose system default, Microsoft YaHei, DengXian, or drop in custom fonts (papertodo.ttf / papertodo.otf).

支持全局快捷键和启动参数吗？Does it support global hotkeys and launch parameters?

可以在设置里为显示、隐藏、切换、新建待办、新建笔记绑定全局快捷键；还支持左右队列 1–9 快捷打开边缘胶囊。也可以用启动参数（--show / --hide / --toggle / --new-todo / --new-note）配合外部快捷键工具或脚本调用。

Bind global hotkeys in settings for show, hide, toggle, new todo, new note; plus left/right queue 1–9 for edge capsules. Launch parameters (--show / --hide / --toggle / --new-todo / --new-note) work with external hotkey tools or scripts.
